AMMU'S BIRTHDAY WEBSITE 💜

FILES
- index.html: the birthday website with your Tanglish letter and violet design
- images/: the three photos you sent

PREVIEW
Open index.html in Chrome to preview. Photos are included and should appear automatically.

MUSIC
The page includes a play/pause control for “Azhake Azhake” from Kathakali. The commercial song audio is not bundled. If you have a copy you are allowed to use, place the MP3 in this same folder and name it exactly: song.mp3. The play button will then play it. Otherwise, use the “Find song online” link in the page. Mobile browsers require the visitor to tap play.

PUBLISH FOR FREE
1. Keep index.html, the images folder, and this README together in one folder.
2. For easiest deployment, sign in at https://app.netlify.com/drop and upload the extracted website folder (or follow Netlify's current instructions if it asks for a ZIP).
3. Wait for the deployment to finish, then copy the public URL and send it to Ammu.
4. If you add song.mp3, publish the folder again with that file included.

Do not share any private photo publicly unless you are both comfortable with that.
